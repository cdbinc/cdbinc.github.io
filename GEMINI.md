# Project: Site Internet

## Project Overview
This project is a workspace for a website. It is currently initialized with Git and contains several documents. 

**Important Note:** The files `index.html` and `Site web.html` are currently misnamed; they appear to be a PDF and a Word document respectively, rather than standard HTML files.

## Directory Overview
The root directory `C:\Users\Admin\Desktop\site internet` is configured for web development and version control. It includes basic toolchain setup (Git, Node.js) and a `.gitignore` file.

## Key Files
- `index.html`: Le fichier principal (HTML5), contient la structure du site.
- `style.css`: La feuille de style (CSS3), gère le design et la responsivité.
- `script.js`: Script JavaScript pour l'interactivité (menu mobile, scroll fluide).
- `Prompt.docx`: Document Word d'origine.
- `.gitignore`: Configuré pour ignorer les dossiers de build et dépendances.

## Usage
### Aperçu
Pour voir le site, ouvre simplement `index.html` dans ton navigateur.

### Version Control
Ce projet utilise Git et GitHub CLI (`gh`). 
- Pour s'authentifier : `gh auth login`
- Pour ajouter les changements : `git add .`
- Pour valider : `git commit -m "Initial commit: Professional website template"`
- Pour pousser sur GitHub : `git push`
